# Kiyoraka Online Music Class 🎵
A promotional website for AI music creation classes featuring a modern glass-morphism design and integrated music player.

## About This Project 📋
This website serves as an advertisement platform for Kiyoraka's AI music creation classes. It showcases the potential of AI in music production, provides samples of AI-generated music, and offers various service packages for potential students.

**Live website:** [https://kiyoraka.github.io/Music-Online-Class/](https://kiyoraka.github.io/Music-Online-Class/)

## Features ✨
* **Educational Marketing** - Promotes AI music creation classes with clear value propositions
* **Interactive Music Samples** - Built-in player with AI-generated songs in English, Japanese, and Malay
* **Service Packages** - Structured presentation of class options and pricing
* **Direct Registration** - WhatsApp integration for easy sign-ups
* **Responsive Design** - Adapts seamlessly to all device sizes with a modern glass-morphism aesthetic
* **Animated Elements** - Floating music notes enhance user engagement

## Technologies Used 🛠️
* HTML5
* CSS3 with glass-morphism effects and animations
* JavaScript (ES6+)
* Font Awesome icons
* GitHub Pages for hosting

## Implementation for Your Own Classes 🚀
If you want to use this template for your own class promotions:

1. Fork the repository:
   ```bash
   git fork https://github.com/kiyoraka/Music-Online-Class.git
   ```

2. Update the class information in `index.html`:
   ```html
   <!-- Update class details -->
   <div class="logo">Your Class Name</div>
   <h1>Your Main Headline</h1>
   <!-- Update pricing and features -->
   ```

3. Replace music samples in the assets/music folder

4. Update the WhatsApp link with your number:
   ```html
   <a href="https://wa.me/YourNumberHere?text=Your%20Custom%20Message" class="register-button">
   ```

5. Deploy to GitHub Pages or your preferred hosting
